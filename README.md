# Project Hub · 本机项目仓库

把本机散落的项目登记到一个地方：按分组管理相关项目、浏览源码和分支、提交到指定分支、
一键用 VS Code / 资源管理器 / 终端打开、运行并实时检查报错。只用 Python 标准库，无需安装依赖。

## 打开

**桌面应用**：双击桌面或开始菜单里的 **Project Hub**（`python hub.py install-shortcuts` 创建）。
也可以 `start-hub.bat` 或 `python hub.py desktop`。

- 默认用 Edge 的应用模式开一个独立窗口（无标签页、无地址栏，有自己的任务栏图标）；
  装了 `pywebview`（`pip install pywebview`）会自动改用原生 WebView2 窗口。
- 关掉窗口即退出，同时停止「运行」页启动的进程。已在运行时再次打开只会多开一个窗口。
- 只想用浏览器：`python hub.py serve --open`，访问 http://127.0.0.1:8790 。

## 功能

| 页面 | 能做什么 |
|---|---|
| 侧栏 | 分组（拖动项目即可换组）、搜索、扫描目录批量登记 |
| 源码 | 文件树 + 语法高亮；可切换查看工作区或任一分支的源码；可直接编辑保存 |
| 变更 | 未提交改动、逐文件 diff，勾选文件提交到当前或**任意其他分支**（不切换工作区） |
| 历史 | 按分支看提交记录与每次提交的 diff |
| 运行 | 运行项目命令，实时输出，自动解析报错位置，点击跳到源码 |
| 问题 | 打开「实时检查」后保存文件即检查（Python/JS/JSON），或做含检查命令的完整检查 |
| 预览 | 有 index.html 的项目可在浏览器里预览（单独端口 8791，隔离于管理接口） |

Agent 可用 `python hub.py find` 按关键词、标签或项目类型查找，用 `tag` 维护标签，
用 `push --dry-run` 预演分支推送。这些命令均支持 `--json`。用法见 [AGENTS.md](AGENTS.md)。

数据保存在 `data/hub.json`（只是登记信息，项目文件留在原处）。
服务只监听 127.0.0.1，并校验 Host 头和 `X-Hub` 请求头，其他网站无法调用。
